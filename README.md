# 🐾 DesktopMof

모후린이 바탕화면을 중력 없이 떠다니는 앱입니다. 따라오기도 하고 도망가기도 하고,
가끔 화면 가장자리에 앉아 졸다가, 오래 안 만져주면 시무룩해집니다.

> 다운로드와 일본어 Q&A: https://desktopmof.github.io/

## 설치

| 쓰는 컴퓨터 | 받을 파일 | 용량 |
|---|---|---|
| 맥 (macOS 12 이상) | [`DesktopMof_1.0.2_universal.dmg`](https://github.com/desktopmof/desktopmof.github.io/releases/download/v1.0.2/DesktopMof_1.0.2_universal.dmg) | 5.0MB |
| 윈도우 (10 / 11) | [`DesktopMof_1.0.1_x64-setup.exe`](https://github.com/desktopmof/desktopmof.github.io/releases/download/v1.0.1/DesktopMof_1.0.1_x64-setup.exe) | 2.4MB |

맥은 `.dmg`를 열고 **DesktopMof**을 `응용 프로그램` 폴더로 끌어다 놓으세요.
윈도우는 `.exe`를 더블클릭하면 설치됩니다.

> 맥용은 **유니버설**입니다. 애플실리콘(M1 이후)과 인텔 맥 모두에서 돕니다.

### 첫 실행 — 경고가 뜹니다

발행자를 확인할 수 있는 배포용 개발자 인증서와 Apple 공증을 받지 않아 OS 확인 화면이
나올 수 있습니다. 배포 출처와 파일을 확인한 뒤 실행 여부를 결정하세요.

**macOS**

1. 앱을 실행 → 열 수 없다는 경고가 뜨면 닫기
2. `시스템 설정` → `개인정보 보호 및 보안` → 아래로 스크롤
3. `"DesktopMof"이(가) 차단되었습니다` 옆의 **`그래도 열기`**

> 자세한 설명은 [Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.
> 관리되는 컴퓨터에서는 이 설정을 바꿀 수 없을 수 있습니다.

**Windows**

"Windows의 PC 보호" 창에서 **`추가 정보` → `실행`**.

## 쓰는 법

실행하면 **갤러리**가 뜹니다. 모후린은 골드 · 실버 · 사쿠라 세 마리이고, 각각 표정 7종
(기본 · 기쁨 · 슬픔 · 화남 · 하트 · 더블하트 · 졸림)이 상황에 따라 바뀝니다.

- **부르기** — 카드를 클릭하면 바탕화면에 나타납니다. 누를 때마다 한 마리씩 늘어납니다(최대 20마리).
- **이름 짓기** — 처음에는 이름이 없습니다. 카드 아래 `＋なまえをつける`에서 직접 지을 수 있습니다.
  이름은 사용자 컴퓨터에 캐릭터별로 저장되며, 변경·삭제할 수 있고 업데이트 후에도 유지됩니다.
- **치우기** — 모후린을 우클릭 → `このモフを巣に戻す`. 전부 치우려면 메뉴바 아이콘 → `みんな巣に戻す`.
- **다시 부르기** — 메뉴바(윈도우는 작업표시줄 알림영역) 아이콘 → `モフを追加`.

> 앱 화면은 일본어입니다.

### 같이 놀기

- 커서를 **빠르게 휘두르면** 놀라서 도망가고, **천천히 다가가면** 따라와 빤히 쳐다봅니다.
- 커서를 **멈추면** 주위를 맴돕니다.
- 모후린 위에서 커서를 **살살 움직이면** 하트가 뜹니다.
- **끌어서** 원하는 자리로 옮길 수 있습니다. 다른 모니터로도 넘어갑니다.
- **더블클릭**하면 폴짝 뜁니다.
- 가끔 화면 가장자리로 가서 **졸다가**, 커서가 다가오면 일어납니다.
- 두 마리가 만나면 **붙어서 쉬거나 부딪혀 튕겨** 나갑니다. 셋 이상 모이면 흩어집니다.
- 한동안 안 만져주면 **시무룩해집니다.**
- 다른 앱 위에서도, 전체화면으로 쓰는 앱 위에서도 그대로 돌아다닙니다.
  모후린을 만져도 쓰던 화면이 바뀌지 않습니다.

## 이름과 보안

- 배포 파일에는 개발자의 개인 이름 설정을 포함하지 않습니다. 같은 종류의 캐릭터를 여러 마리 불러도 이름은 공통입니다.
- 이름은 컴퓨터 안에 저장하며, 앱이 이름이나 커서 위치를 외부 서버로 전송하지 않습니다.
- Mac 1.0.2에서는 화면이 사용할 수 있는 내부 권한과 불러올 수 있는 프로그램·이미지의 범위를 줄였습니다.
- 카메라·마이크·화면 녹화, 로그인이나 사용 통계 수집 기능은 없습니다.
- 현재 Windows 다운로드는 기존 1.0.1입니다. Mac 1.0.2의 보안 변경이 적용된 Windows 버전은 아직 배포하지 않았습니다.

## 잘 안 될 때

**메뉴바에 모후린 아이콘이 안 보여요 (맥)**

메뉴바가 꽉 차 있으면 macOS가 새 아이콘을 **노치 뒤에 숨깁니다.** 앱 문제가 아니라
자리가 없어서 생기는 일이고, 메뉴바 아이콘이 많은 맥에서 자주 납니다.

- 자리를 비우려면: `⌘`(커맨드)를 누른 채 메뉴바 아이콘 하나를 아래로 끌어내면 사라집니다.
  자리가 생기면 다음 실행부터 모후린 아이콘이 나옵니다.
- 아이콘 없이도 쓸 수 있습니다. 모후린을 **우클릭**하면 `モフを追加`(더 부르기)와
  `終了`(끝내기)가 나옵니다.
- 이 경우에는 **갤러리를 닫고 모후린을 전부 치우면 앱이 저절로 종료됩니다.**
  아이콘이 없어 다시 부를 방법이 없는 채로 남지 않도록 한 것입니다.
  응용 프로그램 폴더에서 다시 열면 됩니다.

**"손상되었기 때문에 열 수 없습니다"가 떠요**

파일 손상·변경 등으로 OS 검증에서 문제가 발견된 경우에 나올 수 있습니다.
공개 배포 페이지에서 다시 받아도 계속되면 표시된 메시지와 함께 문의하세요.

**컴퓨터가 느려져요**

모후린 한 마리가 창 하나라 마리당 50MB 안팎을 씁니다. 마릿수를 줄여보세요.

**창을 닫았는데 앱이 안 꺼져요**

메뉴바 아이콘이 보이는 상태라면 의도된 동작입니다. 아이콘으로 언제든 다시 부를 수 있게
남아 있습니다. 완전히 끄려면 메뉴바 아이콘 → `終了`, 또는 모후린 우클릭 → `終了`.
